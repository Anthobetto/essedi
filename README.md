# Essedi — Project Management Tool
**GRAPHICS | SET-UPS | SIGNS | CARPENTRY**
Essedi is an internal management tool designed to streamline operational workflows for a creative services company. It centralizes project, client, task, and budget management, enabling efficient process automation.
## Features
* Centralized client and project management.
* Task tracking with status updates.
* Time tracking and budget management.
* AI assistant powered by Anthropic's Claude API — supports natural language querying and multi-step actions (creating clients, projects, tasks, budgets, and assignments in a single instruction).
* Secure authentication using JWT.
## Tech Stack
**Backend:** Node.js, Express, PostgreSQL
**Frontend:** Next.js, React (TSX), Tailwind CSS
**AI:** Functional integration with Claude (Anthropic). - *Natural language querying and chained tool execution operational; scheduled automations (e.g. email summaries via cron job) under active development.*
**Auth:** JWT + bcrypt
## Status
**Functional MVP.** Core architecture operational; AI-assistant module executes multi-step actions; scheduled automations in progress.
